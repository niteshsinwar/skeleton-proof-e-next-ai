# Scorecard

Filled by `/scorecard` before every release and handoff. Evidence is a link, a count or a recorded run;
never an opinion (11 §5).

| Quality | The product… | Evidence | Score |
|---|---|---|---|
| Value | moves a named user or buyer metric | | MISSING |
| Trust | shows provenance, uncertainty and honest abstention; fakes nothing | | MISSING |
| Experience | is fast, smooth, accessible, persona-shaped, with states that teach | | MISSING |
| Reliability | degrades gracefully, fails closed on safety, recovers | | MISSING |
| Security and privacy | ships day-1 controls: least privilege, isolation, managed secrets, audit | | MISSING |
| Operability | is observable, has runbooks and a rehearsed rollback, one-command setup | | MISSING |
| Economics | knows its cost per task, has a budget, alerts on spend | | MISSING |
| Evolvability | a cold agent can state the problem, scope, next task and stop conditions from the repo | | MISSING |
| Honesty of claims | counts status; labels designed vs built; reports what was not verified | | MISSING |

**Seven planes** (GOLD / SILVER / MISSING): Experience · Orchestration · Intelligence · Knowledge and data ·
Platform · Trust · Improvement.
