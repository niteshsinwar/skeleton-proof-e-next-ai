# Security policy

## Reporting a vulnerability

Please report it privately, never in a public issue: use GitHub's **private vulnerability reporting** on this
repository (Security → Report a vulnerability). We acknowledge within 3 working days and tell you what happens next.

Include what you found, how to reproduce it, and the impact you expect. Please don't access data that isn't yours,
degrade the service, or disclose the issue before a fix ships.

## What we do

A report becomes a failure-log entry and a test that would have caught it (05/SG13, 07/O17). A secret that may have
been exposed is rotated, even if the commit is rewritten (05/SG12).
